Scaffold 扩展 DLL

关于本项目的性质

Scaffold（曾用名 PhobosExt_Changzhi）是基于 官方 Phobos 二次开发的非官方扩展，
沿用其 GPL-3.0 许可，由作者 Chang_zhi 个人维护。
与官方 Phobos 项目组无关：版本与功能不与其同步，也不代表其立场；使用中遇到的问题请向作者反馈，请勿报告给官方。

为《红色警戒2：尤里的复仇》扩展游戏功能的 DLL，面向任务与地图作者，可自由用于任务包与模组。作者 Chang_zhi。

不安装 Phobos 也能独立运行，但少数依赖它的功能不可用；推荐一同使用。

左侧导航栏可展开各页子目录跳转至对应条目；侧边栏顶部的搜索框可直接搜功能名、编号或键名。

安装教程

需通过 Syringe 注入运行。

发布包内容

文件说明放置位置
Scaffold.dll扩展本体，必需游戏根目录
Scaffold.pdb调试符号，仅排查崩溃时用到与 DLL 同目录
FAData_Customized.ini地图编辑器数据，允许用户使用新增触发/脚本地图编辑器目录
说明文档.html本文件，全部功能说明任意
更新日志.txt各版本变更记录任意

安装步骤

  1. 确认游戏版本为 YR 1.001。
  2. 把 Scaffold.dll（推荐连同 .pdb）放入游戏根目录，即 gamemd.exe 所在目录。
  3. 用 Syringe 启动游戏：已装 Ares／Phobos 时直接双击 RunAres.bat；否则执行 Syringe.exe "gamemd.exe"。Syringe 会自动加载游戏目录下的兼容 DLL，无需额外配置。
  4. 把 FAData_Customized.ini 放入地图编辑器目录（仅支持 HDM Edition），编辑器即可识别新增编号。
卸载

删除游戏目录下的 Scaffold.dll（及 .pdb）即可；FAData_Customized.ini 可一并删除。

兼容性

  • 需游戏版本 YR 1.001。
  • 不依赖 Ares 或 Phobos，可单独使用；与 Ares、Phobos 共存不会冲突。
  • 以下功能依赖 Phobos，均需 Phobos v0.5-alpha+：
    脚本动作 5509–5511 与触发动作 653、654、696–699、1100–1105。

[General]
通用设置

1. 混乱机制扩展

1.1 混乱恢复后清除目标

[General]
BerzerkRestoreClearTarget=       ; boolean - 混乱恢复后是否清除当前攻击目标 - (默认 false)

启用后，单位从混乱状态恢复时会清除当前攻击目标、停止移动并转入 Guard 状态，避免恢复后乱跑。

1.2 弹头缩减混乱时间

[WarheadType]
BerserkReduce=                   ; integer - 缩短混乱时间的帧数，负值则延长 - (默认 0)

单位被带此标签的弹头命中时（无论是否造成伤害），混乱时间减少对应帧数。

  • 正值 = 缩短混乱时间；负值 = 延长混乱时间。
  • 减到 0 以下时立即解除混乱，并清除攻击目标、进入 Guard 状态。

2. 文本框黑幕显示

控制文本框在黑幕中是否绘制。

→ 查看对应的触发行为（549–552、579–589）    → 查看文本框样式（[TextBoxTypes]）

[General]
ShowTextBoxInShroud.Waypoint=    ; boolean - 路径点文本框在黑幕中是否显示 - (默认 yes)
ShowTextBoxInShroud.Techno=      ; boolean - 单位文本框在黑幕中是否显示 - (默认 yes)

黑幕判定只看路径点所在格、单位所在格是否被遮挡，不检测整个文本框区域。

3. 盟友建筑维修

[General]
AllowRepairAlliedBuildings=      ; boolean - 是否允许维修盟友的建筑 - (默认 yes)

启用后，玩家可以用维修扳手维修盟友的建筑，费用照常从建筑所属方的资金中扣除。

[WarheadType]
弹头设置

1. 超时空武器扩展

给超时空武器（Temporal=yes 的弹头）增加两种能力：同一目标只被一个武器锁定、攻击时连周围单位一起冻结。

[WarheadType]
; 互斥锁定
Temporal.Exclusive=              ; boolean - 同一目标只被一个单位锁定 - (默认 false)
; 范围冻结
TemporalAOE.Enable=              ; boolean - 启用范围冻结 - (默认 false)
TemporalAOE.CellSpread=          ; double - 冻结范围半径（格） - (默认 2.0)
TemporalAOE.SecondaryWeight=     ; double - 副目标冻结时间权重，可填负值 - (默认 1.0)
TemporalAOE.AffectsAllies=       ; boolean - 是否连友军一起冻结 - (默认 false)
TemporalAOE.AffectsAirborne=     ; boolean - 是否连空中的单位一起冻结 - (默认 false)
TemporalAOE.CenterOnAttacker=    ; boolean - 冻结圆心取攻击者自身而非主目标 - (默认 false)

1.1 互斥锁定：Temporal.Exclusive

启用后，同一目标只会被一个单位锁定：正被其他单位超时空冻结的目标不会被选为攻击对象，对方用的是不是互斥武器都一样。
若多个单位已同时锁定同一目标，只保留一个，其余自动放弃。

注意
  • 只在弹头同时写了 Temporal=yes 与 Temporal.Exclusive=yes 时生效。
  • 限制是单向的：互斥武器不能攻击正被其他单位冻结的目标；而普通超时空武器不受约束，仍可攻击已被互斥武器锁定的目标。
  • 该机制会改变单位的选敌逻辑（见首页「已知问题」）。

1.2 范围冻结：TemporalAOE.Enable

抹除倒计时：
抹除主目标自身需要 10 × 生命值上限 ÷ 武器 Damage 帧，
每个副目标再增加 10 × 生命值上限 × SecondaryWeight ÷ 武器 Damage 帧。
副目标越多、生命值上限越高，抹除越慢；SecondaryWeight 填负值则更快。

例：Damage=100、副目标生命值上限 200、SecondaryWeight=1.0 → 每个副目标多撑 20 帧。

圆心：默认取主目标所在格；开启 TemporalAOE.CenterOnAttacker 后改取攻击者自身所在格。

注意
  • 同一个副目标只累加一次；离开范围/死亡后解除冻结，但已累加的时间不会扣回，这是为了防止主目标被瞬间抹除。
  • 主目标与副目标都被该单位独占：其他超时空武器无法对其开火，所以不会出现多个单位给同一目标叠加时间的情况（为避免 bug）。
  • 正在使用超时空武器的单位不会被选为副目标，避免多个超时空武器互相冻结。
[TechnoType]
单位设置

1. 自动游猎

[TechnoType]
AutoHunt=                        ; boolean - AI 单位自动进入游猎状态 - (默认 false)

该类型的所有 AI 单位自动进入 Hunt 状态，主动搜索并攻击敌方目标。

注意
  • 仅对 AI 控制的单位生效，人类玩家控制的单位不受影响。
  • 已在作战小队中的单位不生效。
  • 位于载具内的单位不生效，离开载具后自动生效。
  • 单位处于部署状态时会先解除部署。
  • 当前攻击目标是地面（强制攻击地面）时，目标会被清除并重新索敌。
  • 目标所在格不可抵达时，本次不执行索敌。
  • 该类型单位会被强制设为不可招募。

2. AI 单位可否被选为目标

[TechnoType]
LegalTargetWhenAIOwner=          ; boolean - AI 控制时能否被其他单位选为攻击目标 - (默认 true)

设为 no 后，该类型在由 AI 控制时不会被其他单位选为普通武器的攻击目标。

注意
  • 不影响人类玩家控制的该类型单位。
  • 仍可被 C4 爆破、碎片伤害等手段命中。

3. 智能火力分配

名字沿用 VHPScan 仅为习惯，其独立于原版逻辑，实现更智能、可操作性更强的火力分配。

[TechnoType]
SmartVHPScan=                    ; 枚举字符串 - 索敌模式 None/LowHealth/FullHealth/Count - (默认 None)
SmartVHPScan.Count=              ; integer - 同一目标最多几个单位同时打 - (默认 1)
SmartVHPScan.CountIdleFrames=    ; integer - 打满人数上限后等这么多帧，超时才允许超编 - (默认 0)
SmartVHPScan.Bias=               ; double - 偏好强度，越大越执着 - (默认 2.0)
SmartVHPScan.UnknownFactor=      ; double - 血量未知目标的分值倍数 - (默认 1.0)
SmartVHPScan.ExcludeFraction=    ; double - 低于该血量比例的目标不打，0=关闭 - (默认 0.0)
SmartVHPScan.Damage=             ; integer - 等效伤害，0=用武器自身 Damage - (默认 0)
SmartVHPScan.Overflow=           ; double - 允许火力溢出比例 - (默认 0.25)
SmartVHPScan.SwitchThreshold=    ; double - 换目标的门槛倍数，越大越不易改目标 - (默认 1.25)
SmartVHPScan.IncludeInflight=    ; boolean - 飞行中的弹药算不算已投入火力 - (默认 true)
注意
  • 与原版互斥：单位自身的 VHPScan 为 Normal 或 Strong 时，本功能不生效。
  • Damage 用于估算「几发能打死」。心控、超时空冻结这类 Damage 有特殊含义的武器，建议手动填一个等效值。

索敌模式

值说明
None不启用。
LowHealth残血优先，血越少越先打。
FullHealth满血优先，血越多越先打。
Count不看血量，只优先分散火力：同一目标最多同时被 N 个单位打，多出来的单位先去打别的目标。

属性说明

属性适用模式说明
CountCount同一目标同时开火的软上限，盟友的单位也计入；填 0 或负数按 1 处理。
CountIdleFramesCount打满人数上限后等这么多帧，等不到才允许超编；0=不等待。
BiasLowHealth／FullHealth偏好强度，越大越执着于残血／满血目标。
UnknownFactorLowHealth／FullHealth刚出现、血量未知的目标的分值倍数：1.0=一视同仁，调低靠后，调高靠前。
ExcludeFraction全部血量低于该比例的目标不再攻击，0=关闭（如 0.05 表示剩 5% 血以下不打）；血量未知的目标不受影响。
Damage全部等效伤害，0=使用武器自身的 Damage。
Overflow全部允许多浪费的火力比例。
SwitchThreshold全部换目标门槛：新目标要好上这么多倍才换，避免来回改目标；1.0=只要更好就立刻换。
IncludeInflight全部已发射、尚未落地的弹药是否算作已投入火力。

示例

; 超时空兵：一个目标只派一个人
[CLEG]
SmartVHPScan=Count
SmartVHPScan.Count=1

; 尤里：优先控制满血目标
[YURI]
SmartVHPScan=FullHealth
SmartVHPScan.Damage=999

; 天启坦克：优先处理满血目标
[APOC]
SmartVHPScan=FullHealth

[Country House]
所属方设置

1. 基地节点跨所属方判定

[Country House]
BaseNodeCrossOwners=             ; boolean - AI 评估基地节点时是否计入所有所属方建筑 - (默认 false)

启用后，AI 判断某个基地节点是否完成时，会把场上所有所属方的建筑纳入考虑。

Button.TextN第 N 个按钮的文字，序号从 1 连续写到 Button.Count；中间跳过会显示空白按钮，超出数量的不会被读取。

[TriggerGroups]
0=FirstTriggerGroup                     ; 索引 - 组名
1=YouTriggerGroup
...

[YouTriggerGroup]                       ; 小节名 = 组名
0=01000004                              ; 键任意 - 成员为触发 ID
2=01000007
...

组名请控制在 31 个字符以内，超长会被截断。

原版 Bug 修复

1. 跟随单位时视野移动行为失效

现象

玩家处于「跟随单位视野」状态时，触发行为 48（移动视野到路径点）与 112（居中视野到路径点）会把视野每帧拉回被跟随的单位，看起来像没执行。

修复后

执行这两个行为时会自动解除跟随状态，视野正常移动到指定路径点。

2. 地图小节中的矿石设置不生效

现象

地图 ini 内没有声明 [Tiberiums] 注册表时，地图中的矿石小节（例如 [Riparius]、[Cruentus] 等）不生效。

修复后

这些小节现已能正常生效。

3. 超级武器瞄准范围环在桥梁上偏移

现象

目标格在桥梁上时，鼠标处的超级武器瞄准范围环会整体向下偏移约 60 像素，与鼠标指针错开。

修复后

范围环按目标格的桥面高度绘制，与指针、实际落点重合。不会向下偏移。
